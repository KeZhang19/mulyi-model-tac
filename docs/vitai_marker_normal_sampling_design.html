Vitai Marker 法线采样

目标不是把一张规则网格“挪到” marker 附近，而是建立两类用途明确、互不混淆的射线： 相机射线负责反解 marker 的三维位置， marker 表面法线负责运行时触觉采样。

BC_Tactile_Lab · 2026-07-25 · 本文只定义设计，不修改运行时实现

一句话结论

离线阶段把每个 marker 的 位置、法线、相机射线、有效性 统一保存于相机坐标系； 运行时把它们变换到世界坐标系，以 marker 为锚点、沿各自外法线向物体发射采样射线。

相机坐标为标定真值 固定 marker ID 每点独立法线 拒绝外推点 不吸附到 32×24 网格

当前实现

  • 在 rubber-link 坐标系中生成规则 32×24 矩形起点网格。
  • 每根手指的全部射线共用一根“平均表面法线”。
  • 蓝色 marker 只参与可视化，不参与 TacMap 采样。
  • HydroShear marker 从稠密网格中取邻近格点，因此分布会继承网格误差。

目标实现

  • marker 几何以 OpenCV 相机坐标系为标准数据。
  • 每个有效 marker 独立提供采样起点与表面外法线。
  • marker ID 固定为 M002–M101；无效槽位保留但输出零。
  • 运行时不再做 nearest-grid snapping。

两种射线的职责

相机标定射线 marker 法线采样射线 rubber 外表面 单位外法线

坐标变换

1. 像素 → 相机射线

Brown 反畸变后，在 OpenCV 相机系中构造单位方向。

2. 相机射线 → marker

与 rubber 外层 mesh 求交，得到相机系位置和 mesh 法线。

→

3. marker → 世界采样射线

随手指位姿变换，并沿每个 marker 自己的法线采样物体。

xₙ, yₙ = BrownInverse(u, v, K, D) d_C = normalize([xₙ, yₙ, 1]) p_C = IntersectOuterRubber(o_C = 0, d_C) n_C = R_CL · n_L p_W = R_WC · p_C + t_WC n_W = normalize(R_WC · n_C) o_W = p_W − b · n_W d_W = n_W assert o_W + b · d_W ≈ p_W

为什么不能真的从 marker 表面直接向外起射： 当物体压入 undeformed marker 表面后，物体边界会落在起点后方，正向射线反而看不到它。 因此“从 marker 打”应解释为射线经过 marker；数值起点沿 −n 后退距离 b。

object_distance = Raycast(o_W, d_W) penetration = valid ? max(b − object_distance, 0) : 0

实现 seam（下一步，不在本文执行）

  1. 离线生成： 在 project_vitai_markers_to_mesh.py 中补齐相机系 ray 与 normal； 不再生成任何外推 marker 供运行时使用。
  2. 运行时射线： 复用 SharpaTacmapLinkSurface，为它增加“显式 starts/directions”这一种输入； 不新建第二套 ray caster。
  3. Revo3 配置： 仅 ours 使用 marker layout；baseline 继续使用规则网格。
  4. 观测与显示： RL、HydroShear、debug visualization 共用同一份 marker ID、valid mask、世界坐标射线。

这个 seam 把 Brown 反解、URDF 外参、坐标变换和有效性隐藏在一份小的数据契约后面； 调用者只需要 marker 世界射线与 mask。

验收条件

  1. 像素回投：所有有效 marker 的 Brown 回投误差 ≤ 0.5 px。
  2. 表面一致：marker 位于 rubber 外层 mesh，且不使用 nearest-surface 回退。
  3. 方向一致：||n_C|| = 1，并满足 dot(n_C, d_C) > 0。
  4. 射线过点：o_W + b·d_W 与蓝色 marker 重合。
  5. 深度符号：无接触为 0；压入 δ 时输出约为 δ，而不是 gap。
  6. 形状稳定：每指始终 100 槽，invalid slot 永远为 0。
  7. 可视化同源：屏幕上的蓝点、法线和实际 Warp ray 使用同一 tensor。

实施前只需确认一个物理参数

marker_ray_backoff_m = b 必须大于最大预期压入深度，同时不能穿过不相关几何。 它应保留为配置项，并在 index 指尖上用已知压入量做一次标定；其余结构不需要再做设计选择。
