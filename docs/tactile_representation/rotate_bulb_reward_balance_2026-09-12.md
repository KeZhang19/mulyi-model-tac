**频率与折扣**

60Hz表示每秒执行60次策略动作；物理每个动作仍推进4个子步。当前没有降低控制频率更合适的实测依据。
奖励乘以dt是积分，不会额外压低回合后段的即时奖励；造成早期决策偏向近期收益的是每步gamma。
[RewardManager实现](https://isaac-sim.github.io/IsaacLab/main/_modules/isaaclab/managers/reward_manager.html)
明确将每项函数值乘weight和dt。

用物理时间写作 `gamma=exp(-step_dt/tau)`。0.99对应tau约1.66秒、半衰期1.15秒；
0.999对应tau约16.66秒、半衰期11.55秒。延迟t秒的回报权重为 `gamma^(60*t)`：

| 延迟 | 原gamma=0.99 | 当前gamma=0.999 |
| --- | ---: | ---: |
| 1秒 | 54.72% | 94.17% |
| 3秒 | 16.38% | 83.52% |
| 5秒 | 4.90% | 74.07% |
| 10秒 | 0.2405% | 54.86% |
| 15秒 | 0.01179% | 40.64% |
| 20秒 | 0.0005784% | 30.10% |
| 30秒 | 0.000001391% | 16.52% |

这是相对于较早决策时刻的折扣，不是晚期状态本身的即时奖励被缩小；低gamma也不意味着长任务必然无法学习。
如果今后改变控制频率，需要按同一tau重算gamma，不能把0.999机械沿用到所有Hz。

保持32步rollout和lambda=0.95，先隔离奖励与gamma的改变。32步在60Hz下覆盖0.533秒，
但RSL-RL用末端value bootstrap估计更远回报，因此不必直接扩到1800步。
GAE的gamma×lambda控制优势残差的偏差与方差，与任务折扣视野不是同一个参数。
参考[RSL-RL返回值计算](https://raw.githubusercontent.com/leggedrobotics/rsl_rl/v2.3.3/rsl_rl/storage/rollout_storage.py)。

训练与PLAY的回合上限随后由30秒调整为20秒，即1800步降为1200步；成功、掉落仍提前结束。
目前没有完整成功轨迹的耗时分布，20秒先为三圈旋出、换抓和搬运保留余量；15秒可在取得
成功耗时数据后做对照。此前平均约3秒结束主要来自掉落，缩短超时不会直接改善这类回合。
60Hz、gamma=0.999以及下述阶段奖励预算保持不变；缩短上限也不能代替折扣与奖励平衡调整。
剩余时间观测随新上限归一化，成功保持0.3秒和换抓宽限0.2秒保持原值。启动时应核对实际
保存的`episode_length_s`，旧命令中的`env.episode_length_s=30.0`会覆盖新的默认值。
对比日志时，IsaacLab的`Episode_Reward/*`以回合上限秒数作分母：相同累计奖励在20秒配置中
显示为原30秒配置的1.5倍，不代表策略进步。应同时比较原始回合回报与逐回合成功/掉落率。

**有效分数预算**

| 阶段 | 旧有效量级 | 当前有效量级 |
| --- | --- | --- |
| 接近外壳 | 最多1分/秒，另有最多5分进度 | 只保留最多1分新进度 |
| 初始接触 | 接触0.5分/秒+塑形0.5分/秒 | 塑形0.25分/秒，累计最多1分 |
| 旋出三圈 | 最多120分，完成瞬间另20分 | 最多6分，不在旋出瞬间加完成奖 |
| 释放后稳定 | 无独立阶段预算 | 0.5分/秒，最多2分 |
| 释放后持续抓稳0.3秒 | 无独立里程碑 | 一次性2分 |
| 搬运引导 | 两项最多12分/秒常驻奖励 | 只奖新最佳目标进度，最多4分 |
| 最终稳定成功 | 条件满足后20分/秒 | 首次成功10分，当步结束回合 |
| 释放后掉落或越界 | 终止，但无显式扣分 | 一次性扣6分 |
| 每项动作正则 | −0.005×动作平方和（上限1000）/秒 | 系数−0.001，最大扣1分/秒 |

除动作正则外，默认三圈的正奖励理论总上限为26分（1+1+6+2+2+4+10）；
实际接近与搬运得分取决于初始距离，不保证达到上限。角度和轴向耦合、进度历史最高值、
0.2秒换抓记忆、物理释放及严格最终成功判据保留。

“对齐”指比较每秒有效奖励与每阶段累计回报。事件可以在一个控制步内付清，
连续引导在多个控制步累积；强行把所有函数原始输出或单步峰值变得相同，会再次让事件受dt影响。
事件、进度及预算型连续项按credit/dt返回，再由管理器乘dt，所以不会把−6分误缩为−0.1分。
这也没有假设所有奖励在当前策略下出现频次相同：搬运尚未发生时，不能通过无限放大稀有项宣称已达到经验均值相等。

**行为约束和范围**

- 搬运在第一次实际释放后建立势函数基线；阶段切换本身不得分，停着不动、往返、无接触移动后重新抓住均不能补领历史进度。
- 初始抓持和释放后稳定都有累计预算，增大gamma也不会使原地保持无限刷分。
- 稳定塑形允许不超过0.2m/s的平移，避免惩罚合理搬运；最终成功仍使用更严格的速度和保持阈值。
- 掉落与越界读本步TerminationManager标志，奖励在reset之前计算；重叠仅扣一次，单纯超时不扣。
- 成功标记仍表示当前是否稳定成功，一次性支付另有锁存状态；满足严格成功条件后当步发奖并终止，避免成功后的动作成本诱导主动掉落。
- 成功终止通过独立的同条件计时器读取奖励管理器最终参数，后置Hydra覆盖同步生效。终止先计算、奖励后计算、最后reset，两边每个控制步各更新一次。
- CommandManager的回合成功日志直接读取本步成功终止标志，避免场景reset先清空成功状态、导致日志漏掉成功回合。
- PPO结构与观测维度兼容旧权重，但旧critic估值不再对应新的尺度；实际恢复训练需要验证其适应过程。
- D-Peg继承Rotate-Bulb的PPO配置，已显式固定自身gamma=0.99。RL-Games与独立RotateBulbCustom的配置不在本次RSL调整范围。

这些数值是训练实验起点。降低旋出奖励后，不应直接沿用旧建议的−30/−60掉落扣分。
如果释放率明显下降而持有时长不改善，应减小或渐增失败惩罚；评估应同时关注释放率、
释放后持有时长、真实逐回合最终成功与掉落计数，而非仅关注总reward。
