## 已完成的奖励修改

辅助项 `any_finger_contact` 现在按五根指尖独立计分：

```text
奖励率 = 0.02 × Σ clip(F_i / 0.5 N, 0, 1) 分/秒
单步奖励 = 奖励率 × step_dt
```

每根指尖达到 0.5 N 获得 0.02 分/秒；1–5 根分别为 0.02、0.04、0.06、0.08、0.10 分/秒。小于阈值保留线性引导，例如一根指尖 0.25 N 获得 0.01 分/秒。单根施加更大压力不能代替其他指尖获得奖励。

仅使用指尖对灯泡的过滤接触力，桌面和灯座接触不计分；旋出前后均有效，掉落或越界失败当步停止支付。与原有有限预算的抓握奖励独立，与模态还原观测开关独立。全五指持续接触 20 秒最多获得 2 分。

惩罚约相当于旋转正奖励的 25%，有成本但没有在总量上盖过旋转奖励。平均抓握引导只拿到预算的约 3.2%，不能把低抓握奖励解释为“预算已经耗尽”。较多旋转仍发生在接触较差的阶段；抓握加权旋转奖励还允许 0.2 秒衰减记忆，因此得到该奖励不代表整个回合一直抓稳。

新增辅助项有助于降低接触门槛，并对多根指尖持续接触给出信号。不过最新训练的平均动作惩罚率已约为 0.0394 分/秒：一根指尖满额 0.02 分/秒不足以完全抵消，两根满额 0.04 分/秒大致相抵，更多指尖才有较明显余量。这里比较的是观察到的均值，不能保证抵消所有动作；动作没有裁剪到 `[-1, 1]`。目前接触本身很少，新增项实际拿到多少仍需要新训练验证。

探索方面，`init_noise_std=1.0`，模型 750 的平均标准差为 1.430，最新日志已为 1.593。28 个动作共用 `RelativeJointPositionActionCfg(scale=0.1)`，按每个物理子步当前关节位置加相对目标；没有原始动作裁剪。750 轮时噪声对应的目标增量标准差约为 0.143 rad，**这是目标增量，不是实际单步关节位移**。标准差和熵持续升高，证据不支持探索熵塌缩；是否噪声过大需要固定其他变量的训练对照。

更新方面，PPO 的 KL 自适应调度按 minibatch 调整学习率：KL 超过 0.02 时降为原来的 1/1.5，最低 1e-5。模型 750 的优化器学习率正处于 1e-5，最近日志已经部分回升，故不能说它始终固定在最低值。较低更新幅度可能拖慢新行为建立，但模型仍在进步，不能称为停止学习。

`gamma=0.999` 在 60 Hz 下对应约 16.66 秒折扣时间常数；`lambda=0.95` 下 TD 残差的几何加权尺度约 0.327 秒，rollout 为 0.533 秒。这可能影响延迟奖励的信用分配，但 critic 自举会延伸价值传播，不能将其误读为策略只能学习 0.33 秒后的收益。当前直接证据更强的问题仍是接触与后续阶段门控。

## 一个会影响观感的统计口径

`unscrew_reached_3_turns` 要求圈数达到 `3 - 1e-5`，而物理释放条件要求角向和轴向进度都达到 `0.999`，初始 3 圈时相当于约 **2.997 圈**。因此释放时记录为 2.998 圈的回合不会进入“达到 3 圈”统计。

这会低估“已拧出”的比例。确定性回放中确实有 5/8 物理释放，但按当前严格三圈指标只有 1/8 达标。现有 `released` 标签是状态占比性质的指标，也不等价于每回合曾释放率。判断旋出能力应结合实际释放记录和最大圈数；下一次增加指标时，宜单列每回合 `ever_released`。

## 下一步的优先顺序

1. 让本次逐指辅助项进入新训练，先观察实际辅助奖励、各指接触占比、对向接触持续时间和每回合曾释放率。先保持动作惩罚、gamma 等不变，判断接触是否增加以及旋转是否继续改善。
2. 若仍很快失去接触并长期贴限位，再单独对照机械臂/手指动作尺度或探索调度；不要继续增加探索噪声。现有回放表明仅降低采样噪声不足以解决问题。
3. 若旋出率上升但持稳仍为零，再检查释放阶段的引导衔接。当前奖励需要已释放、离开支撑、对向接触以及低速度；一次性持握奖还需持续 0.3 秒。它们同时满足前几乎不给信号，单纯提高末端成功奖未必能帮助发现这一阶段。
4. 若接触改善后仍学习缓慢，再独立检查 KL 自适应学习率、rollout 和 lambda。此次没有修改这些参数。
