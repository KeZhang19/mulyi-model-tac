# Optional socket collision candidates

These assets are generated by `../tools/optimize_collisions.py`. The canonical
`../socket.usd` is unchanged. Every candidate retains the exact original
VisualMesh, TactileSurface, rigid-body settings, contact offsets, and materials.
The convex candidates also retain the original floor collider verbatim.

| Asset | Collision shapes | Maximum cavity narrowing | Minimum radial shaft clearance |
|---|---:|---:|---:|
| `socket_48.usd` | 36 | 29.44 µm | 0.7227 mm |
| `socket_32.usd` | 26 | 66.21 µm | 0.6886 mm |
| `socket_triangle.usd` | 1 / 664 triangles | Exact visual mesh | See physical validation |

The convex names specify the angular sampling resolution over a full circle,
not the final collider count. One independent beveled flat wall is combined
with arc sectors and the blind floor. This preserves the D-flat and the 1 mm
entrance chamfer while avoiding a nonconvex transition inside individual hulls.
Geometric errors were measured by ray-intersecting the actual convex hulls at
65,536 angles and 73 heights, including 65 heights across the entrance chamfer.

The triangle mesh is an experimental candidate and must pass the same physical
acceptance checks. PhysX supports triangle collision meshes on kinematic rigid
bodies, but the actual solver and contact-report behavior must be verified in
the running Isaac Sim version.

The validator now measures contact-force peaks at every 240 Hz physics step.
The trajectory remains sampled at 20 Hz. The 0.05 N acceptance threshold is
unchanged: repeated impulses can alias to all zeros in the slower trajectory,
so the trajectory samples alone must not be used to decide whether a contact
occurred. Both the full-rate and trajectory peaks are included in each report.

Run the unchanged force-controlled acceptance checks with explicit asset
selection before training with either convex candidate:

```bash
python assets/d_peg_insertion/tools/validate_insertion_physics.py \
  --socket-usd assets/d_peg_insertion/collision_variants/socket_48.usd \
  --expected-socket-colliders 36 --socket-approximation convexHull \
  --headless --device cuda:0 --report /tmp/socket_48_physics.json
```

The geometric checks do not prove simulation speed or policy equivalence.
Changing the socket intentionally changes its asset hash, and therefore needs
explicit training-contract provenance when migrating a previous checkpoint.
