2026-10-12 范围约定：本页主标定仅包含视触觉模态、台架位姿和标准六维力。
压阻 ADC／`rp1/rp2/rp3`／`py_force_calibration` 暂归为[其他标定](../../../ros_ws/src/py_force_ws/doc/other_calibration/README.md)，
不作为主流程前置、采样通道或验收项；标准六维力及安全保护保留。

2026-10-11按本地代码和已有记录整理。这里是当前工作顺序；本轮目录整理未执行真机标定。
机械／数据契约的细节继续维护在[机械说明第8–14节](机械标定台仿真搭建_README.md#8-标定目标与系统分工)。
实现采集／训练转换时另读[真机采集数据接口](real_data_interface.md)，逐层核对字段、参考和规范配对。

## 工作顺序与产出

1. **核对实物版本。** 登记手、压头、支架、相机SN和已确认手指映射；核对URDF、关节姿态和工具尖端frame。
   不把V4源支架、M6×16派生完整包与旧M6×20方案混用。
2. **复核坐标和接触零点。** 读取 `config/` 的坐标及模型预定位点，核实实际轴方向、TCP、转台外参及平台高度差异。
   从食指DIP＋球压头开始；模型预定位点和平台高度都不是手指接触零点。
3. **核对测力与时钟。** 按硬件说明保留六维力原值、ROS时间、主机接收单调时钟、位姿查询窗口及数据新鲜度。
   组合状态是缓存位置，未校时的Revo3／相机时间不能直接相减。
4. **采集空载参考。** 明确空载状态后使用 `collect_real_trimodal.py --phase baseline --confirm-unloaded`。
   用新目录保存原RGB和会话；既有 `captures/` 中的会话作为原始证据保留。
5. **受控加载与联合记录。** 复用同SN空载会话，记录加载／稳定／卸载全过程、实际位姿和独立力；保留失败和缺测。
   当前相机入口可以复用参考，但不会驱动台架或同步测力；联合采集适配与验收仍是待完成工作。
6. **离线对应、拟合与转换。** 先检查原始哈希、尺寸、坐标版本和单位；按真实轨迹确定仿真对应状态，再使用压力工具拟合。
   SDK原生三模态、机械台NPZ与Isaac训练manifest是三种契约，不能通过凑维度或复制字段当作已配对数据。
7. **独立复验。** 使用未参与拟合的位置／深度／重复回合，记录误差、失败和有效样本数；物理参数写入须另有明确授权。
   联合标定和跨域转换通过后，才进入 `collection/` 的训练数据准备与正式表示训练。

各阶段执行条件和完整参数以[硬件说明](../hardware/README.md)、
[机械标定顺序](机械标定台仿真搭建_README.md#9-真机标定顺序)及
[验收清单](机械标定台仿真搭建_README.md#14-验收与下一步实现清单)为准。

## 输出归属

| 目录 | 保存内容 |
| --- | --- |
| `captures/<新会话>/` | 原始RGB、时间、session与派生三模态；源数据保持不可覆盖 |
| `outputs/simulation/<新运行>/` | 仿真回合、config／frames／manifest与验证报告 |
| `outputs/<新诊断>/` | 离线拟合、比较、验证及失败证据 |
| `datasets/<新数据集>/` | 已完成契约转换的训练分片与mmap缓存 |
| `config/` | 经核实的配置／坐标版本；更新时保留变更证据 |
| `provenance/` | SDK复制及目录迁移清单；不混入本轮测量结果 |

新输出目录必须不存在。命令从仓库根目录运行；离线规模检查见[总入口](../README.md#离线检查与运行条件)。
历史源数据、模型和失败记录不因目录整理删除或重新生成。
